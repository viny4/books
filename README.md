## 🚀 How to Use

1. **Browse** a folder from the tables above, or open the **[full catalog](BOOKS_LIST.md)**.
2. **Search** by title with GitHub's file finder (press `t` on the repo page).
3. **Clone locally:** PDFs are stored with [Git LFS](https://git-lfs.com), so install it first:
   ```bash
   git lfs install
   git clone https://github.com/viny4/books.git
   ```
   The full repo is about 7 GB. To clone without downloading the PDFs, use `GIT_LFS_SKIP_SMUDGE=1 git clone ...` and then fetch only what you need with `git lfs pull --include="AI Books/*"`.
